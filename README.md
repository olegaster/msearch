--------------------
mSearch
--------------------
Full-text search component for MODX Revolution 3.x
with morphological analysis support.
--------------------

Requirements:
- MODX Revolution 3.0+
- PHP 8.1+
- VueTools >= 1.2.0-pl (for admin panel)

Features:
- Morphological analysis (Russian, English, German)
- Word index with configurable field weights
- Search aliases (synonyms and replacements)
- Query statistics tracking
- Automatic indexing on resource save
- Vue-based admin panel
- Autocomplete support

Documentation:
https://docs.modx.pro/components/msearch

Issues and suggestions:
https://github.com/modx-pro/mSearch/issues
